## Prerequisites

- [Terraform](https://developer.hashicorp.com/terraform/install) >= 1.5
- [Azure CLI](https://learn.microsoft.com/en-us/cli/azure/install-azure-cli) (authenticated via `az login`)
- An Azure subscription
- A Databricks account (Premium SKU for Unity Catalog)

## Usage

Read it in the blog posts, or clone the repo and run the code yourself!
